# Aarzoo Gupta — Portfolio

A clean, responsive personal portfolio built with only:
- HTML
- CSS
- Vanilla JavaScript
- One local profile image

No React, Node.js, npm, build process, or VS Code extension is required.

## Run locally

1. Open this folder in VS Code.
2. Open `index.html` in a browser.
3. The website will work immediately.

You can also use VS Code's Live Server extension, but it is optional.

## Files

- `index.html` — all portfolio content
- `style.css` — design, responsive layout and animations
- `script.js` — navigation and scroll animations
- `assets/aarzoo-profile.jpg` — profile photograph

## Publish with GitHub Pages

1. Create a new **Public** GitHub repository, for example `aarzoo-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Open the repository's **Settings**.
4. Choose **Pages**.
5. Under the publishing source, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save.
8. GitHub will provide your live website link.
